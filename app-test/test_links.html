Frogtab link tests

Run just app-test from the repository root. To run the tests without just, serve the repository root and open this page in a browser:

python3 -m http.server 8124

The tests embed app/index.html in the iframe below and drive the real app. They cover the link overlay: rendering, re-render triggers, scroll sync, hit-testing, the hand cursor, and the tooltip.

With ?platform=mac in the URL, the tests load the app with navigator.platform spoofed as MacIntel, so the Mac branches of the modifier logic run on any OS. CI runs both modes.

The page title shows the result: Link tests: all passed.

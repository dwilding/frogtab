Frogtab link tests

Run just app-test from the repository root. To run the tests without just, serve the repository root and open this page in a browser:

The tests embed app/index.html in the iframe below and drive the real app. They cover the link overlay: rendering, re-render triggers, scroll sync, hit-testing, and the hand cursor.
